# Abdallah Al Homsi — Portfolio

Personal portfolio site. Single-file React component, built with **Vite**, **React**, and **Tailwind CSS**.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build      # outputs to dist/
npm run preview    # preview the production build locally
```

## Deploy

Deployed on [Vercel](https://vercel.com) — every push to `main` triggers an automatic redeploy.
